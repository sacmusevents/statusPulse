# StatusPulse - Brand Guidelines

## Product Overview

**Name:** StatusPulse
**Tagline:** "Real-time feedback for any group"
**Baseline:** Silent, instant status communication platform

### What We Do
StatusPulse enables one person to control visual status signals that multiple viewers see instantly. Perfect for non-verbal feedback in group settings like classrooms, meetings, conferences, and events.

---

## Brand Identity

### Core Values
- **Real-time**: Instant synchronization across all devices
- **Silent**: Non-disruptive communication
- **Simple**: Three colors, one tap
- **Inclusive**: Works on any device with a browser
- **Empowering**: Gives control to facilitators, visibility to participants

### Brand Personality
- Professional yet approachable
- Confident but not aggressive
- Clear and direct communication
- Technical but human-friendly
- Action-oriented

## Visual Identity

### Color Palette

#### Primary Colors
- **Pulse Red:** #FF4D4D (Confidence, urgency, attention)
- **Pulse Yellow:** #FFD700 (Caution, awareness, transition)
- **Pulse Green:** #4CAF50 (Success, clarity, ready)

#### Neutral Palette
- **Dark Navy:** #1A1A2E (Primary text, backgrounds)
- **Light Gray:** #F5F5F5 (Secondary backgrounds)
- **Medium Gray:** #757575 (Secondary text)
- **White:** #FFFFFF (Primary backgrounds)

#### Accent Colors
- **Pulse Blue:** #2196F3 (Links, CTAs, highlights)
- **Status Green:** #00C853 (Connected status, success states)

### Color Usage Guidelines
- **Status Colors (Red/Yellow/Green):** Core product functionality - use exactly as specified
- **Pulse Blue:** Call-to-action buttons, links, interactive elements
- **Dark Navy:** Headings, primary text
- **Medium Gray:** Secondary text, descriptions, disabled states
- **Light Gray:** Subtle backgrounds, dividers

## Typography

### Font Family
**Primary:** Inter or Roboto (modern, clean, highly legible)
**Fallback:** -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif

### Font Scale

| Element | Size | Weight | Usage |
|---------|------|--------|-------|
| H1 (Page Title) | 32-36px | 700 (Bold) | Main headings |
| H2 (Section Title) | 24-28px | 700 (Bold) | Subheadings |
| H3 (Subsection) | 18-20px | 600 (Semibold) | Minor headings |
| Body Text | 14-16px | 400 (Regular) | Main content |
| Small Text | 12px | 400 (Regular) | Secondary info, captions |
| Button Text | 14-16px | 600 (Semibold) | CTAs |

### Line Height
- Headings: 1.2
- Body: 1.6
- Labels: 1.4

## Logo

### Logo Concept
**"Pulse Traffic Light"** - A modernized traffic light icon with a subtle pulse/heartbeat effect

### Design Specifications
See `LOGO_SPECS.md` for detailed specifications

### Logo Variations
1. **Horizontal Logo** - Logo + text (primary use)
2. **Vertical Logo** - Logo on top, text below (app store, limited space)
3. **Icon Only** - Just the traffic light (app icon, favicons)
4. **Icon + Text (Compact)** - Icon and text inline (headers, small spaces)

### Clear Space
- Minimum 16px of clear space around logo on all sides
- Should never be less than 32px wide in any application

### Logo Colors
- **Primary:** Full color (traffic light: Red/Yellow/Green with pulse)
- **Monochrome Dark:** All dark navy (#1A1A2E) - for light backgrounds
- **Monochrome Light:** All white - for dark backgrounds
- **Do Not Use:** Gradients, filters, or alterations to the core design

## Microcopy Guidelines

### Tone
- Clear and direct (no jargon)
- Action-oriented
- Friendly but professional
- Never passive or hesitant

### Examples

**Good:**
- "Create Display" (action verb)
- "Join with code" (specific action)
- "Connected ✓" (confirmation)
- "Waiting for your status..." (engaging)

**Avoid:**
- "Select Session" (passive, vague)
- "Enter a code" (less direct)
- "Connected" (missing confirmation)
- "No input received" (negative framing)

### Button Labels
- Use action verbs: Create, Join, Share, Start, Connect
- Be specific: "Create Display" not "Create"
- Use proper capitalization: Title Case for buttons

## Photography & Imagery

### Visual Style
- Clean, minimal aesthetic
- Real people in real situations (classrooms, meetings, events)
- Show the problem being solved (confusion, disconnection)
- Show the solution (clarity, feedback, connection)
- Warm lighting, inclusive diversity

### Do's
✓ Use actual classroom/meeting scenarios
✓ Show different use cases (education, business, events)
✓ Include diverse participants
✓ Focus on emotional moments (clarity, "aha", connection)
✓ Use high-quality, modern photography

### Don'ts
✗ Stock photo clichés
✗ Overly polished/fake scenarios
✗ Generic office imagery
✗ Dark, serious, corporate tone
✗ Exclude or misrepresent diverse groups
